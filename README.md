# portfolio

[https://lflucasferreira.github.io/portfolio/](https://lflucasferreira.github.io/portfolio/)

## Structure

| Page | Content |
|------|---------|
| `index.html` | Hub: hero, about, skills, explore cards, education, contact |
| `work.html` | Experience, recommendations, achievements (+ left TOC) |
| `projects.html` | Projects + open source / qametrics (+ left TOC) |
| `metrics.html` | Custom metrics, Looker, severity & priority (+ left TOC) |
| `growth.html` | Performance & growth (existing) |

Legacy hashes on `index.html` (e.g. `#metrics`, `#experience`) redirect to the new pages.

```bash
npm run dev
```
