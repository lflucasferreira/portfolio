03-B · Task & Action
Task
Re-architect CLP component test strategy
Audit all 180+ existing CLP tests — identify which were component vs E2E
Define tiered strategy: unit → component → integration → E2E
Establish fast-feedback suite target: < 10s per component scenario
Ensure zero regression on coverage — same confidence, faster execution
Action
Isolated component mounting in Cypress CT
Migrated component tests from Cypress E2E → Cypress Component Testing
Adopted Page Object Model with shared fixture factories — reused across 6 flows
Stubbed external API calls via cy.intercept() — eliminated backend dependency
Added GitLab CI stage: component suite runs in parallel with E2E, not blocking it
Documented pattern in team wiki → adopted by 2 other squads

03-D · Technical Evidence · POM + Cypress CT 
// pages/clp-step1.page.ts — Page Object Model
export class Clp1Page {
  visit() { cy.mount('<app-clp-step1 />', { imports: [ClpModule] }); }
  get nameInput() { return cy.findByLabelText('Legal name'); }
  get nextBtn()  { return cy.findByRole('button', { name: 'Continue' }); }
}

// spec: clp-step1.cy.ts — component test (runs in 7s, no backend)
describe('CLP Step 1 — Name validation', () => {
  beforeEach(() => {
    cy.intercept('POST', '/api/clp/validate', { fixture: 'clp-valid.json' });
    new Clp1Page().visit();
  });

  it('blocks submit when name is empty', () => {
    const page = new Clp1Page();
    page.nextBtn.should('be.disabled');
  });

  it('proceeds to Step 2 with valid input', () => {
    const page = new Clp1Page();
    page.nameInput.type('Lucas Ferreira');
    page.nextBtn.click();
    cy.url().should('include', '/clp/step-2');
  });
});

04-C · Custom QA Metrics
PPI — Process Performance Index
Automation ROI per sprint
Measures automated test maintenance cost vs bugs caught before production. Positive PPI means automation is returning more value than it costs to maintain. Tracked weekly via Grafana dashboard — avg PPI +3.2 over last 6 months.
SRM — Sprint Risk Metric
Delivery confidence score
Weighted sum of open defects, unstable tests, and pending reviews at sprint close. Target SRM ≤ 12 per sprint. Q4 2024 average: 8.4. Surfaced in sprint review to align with PM on scope risks.
RBD — Regression Bug Density
Escaped bugs per 100 test cases
Tracks production regressions attributable to test gaps. Baseline was 4.1 RBD at onboarding; current: 0.9 RBD. 78% reduction over 2 years — driven by coverage expansion and component isolation.
Task Score — 6-Gate Quality Model
Objective delivery quality
6 criteria scored 0–5 per task: Test Coverage, Bug Detection, Documentation, Automation Quality, Delivery Timeliness, Collaboration. 26.6/30 avg across 30+ sprints. Excellent ≥ 25.
